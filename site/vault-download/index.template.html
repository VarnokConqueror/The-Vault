How to Install

  1. Choose the Android APK for phones or the Windows installer for PC.
  2. On Android, open the APK and allow installs from your browser if Android asks.
  3. On Windows, run the installer and allow it through SmartScreen if Windows prompts.
  4. Finish installation and open The Vault from the app list or desktop shortcut.

What to Expect

  • This is the direct Android install, not the Play Store version yet.
  • Updates will need a new APK download until Play rollout is live.
  • If installation fails, remove an older incompatible build first.
